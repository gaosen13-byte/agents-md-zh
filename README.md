# AGENTS.md 中文生成器

一个纯静态、免构建的中文 AGENTS.md 生成器。选择项目类型、技术栈和协作偏好后，即可生成结构清晰的项目协作指南，并复制或下载为 `AGENTS.md`。

## 使用方法

1. 直接在浏览器打开 `index.html`。
2. 选择项目类型，可多选技术栈，也可以填写其他技术栈。
3. 按需要打开或关闭协作偏好，点击“生成 AGENTS.md”。
4. 检查预览，点击“复制内容”或“下载文件”。
5. 将文件放在项目根目录，并按项目实际情况补充命令、目录说明等信息。

无需安装依赖或构建。也可以将仓库内容直接发布到 GitHub Pages：在仓库设置中启用 Pages，并选择对应分支和目录即可。

## 内含模板

- `templates/网站项目.md`：网站项目协作说明
- `templates/Python脚本项目.md`：Python 脚本项目协作说明
- `templates/浏览器插件项目.md`：浏览器插件协作说明

模板可以直接复制到项目根目录并命名为 `AGENTS.md`，再按实际技术栈和工作流调整。

## 项目文件

- `index.html`：页面样式、交互和生成逻辑均在此文件中，无外部运行时依赖。
- `templates/`：可直接复用的中文 Markdown 模板。
