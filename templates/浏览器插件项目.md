# AGENTS.md

## 项目概览

- 项目类型：浏览器插件
- 技术栈：以仓库当前的浏览器支持范围、manifest 版本和依赖配置为准。

## 工作约定

- 修改前检查 manifest、权限声明、后台脚本、内容脚本和消息传递关系。
- 遵循最小权限原则；新增权限、主机访问范围或数据收集前先征求用户同意。
- 保护用户数据，不在日志或代码中暴露令牌、凭据及个人信息。
- 保持浏览器兼容性和现有构建、打包方式；不擅自更改发布配置。
- 为新增或变更行为补充适当测试，并检查相关浏览器 API 的使用方式。
- 未经用户明确同意，不删除文件或引入新依赖；新增注释使用简体中文。
- 完成后汇报改动、验证结果和未解决事项。
